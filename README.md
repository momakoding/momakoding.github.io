# momakoding.github.io

Momakoding website built with Nuxt 4 and Tailwind CSS v4, deployed to GitHub Pages.

## Commands

```bash
# Install dependencies
pnpm install

# Start development server
pnpm run dev

# Run TypeScript type check
pnpm run typecheck

# Generate static site into .output/public
pnpm run generate

# Preview production build locally
pnpm run preview
```
